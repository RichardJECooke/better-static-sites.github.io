# astro-gen-markdown-pages

> Renamed to [`astro-better-gen-markdown-pages`](https://www.npmjs.com/package/astro-better-gen-markdown-pages).

This package is deprecated. Version 1.1.1 is a thin re-export of
`astro-better-gen-markdown-pages` so existing installs keep working, and it is the last
release under this name.

## Migrating

```
npm uninstall astro-gen-markdown-pages
npm install astro-better-gen-markdown-pages
```

Then update your imports:

```diff
-import x from 'astro-gen-markdown-pages';
+import x from 'astro-better-gen-markdown-pages';
```

Everything else is unchanged. See the [documentation](https://better-static-sites.github.io).
